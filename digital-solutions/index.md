## Exam format (QCAA Digital Solutions syllabus v1.4, p.47)
| | |
|---|---|
| Type | External examination — combination response (**25%**) |
| Content | **Unit 4: Digital impacts** |
| Perusal | 5 minutes |
| Working time | 120 minutes |
| Responses | Multiple choice; short and extended response; sketches/diagrams; algorithms and calculations; unseen stimulus |
| Calculator | QCAA-approved **non-programmable scientific** calculator |

::: info In the 2024 and 2025 papers
**66 and 67 marks**: 10 multiple choice, 36 marks of short response, and one multi-part extended response (20–21). Privacy principles, CIA risks, data flow diagrams, pseudocode with JSON and usability evaluation recur. See [past papers analysis](/digital-solutions/past-papers).
:::

## Assessment objectives
1. **Recognise and describe** UX elements, programming features, data exchange components, privacy principles and processes.
2. **Symbolise and explain** programming ideas, data specifications, data exchange processes and data flow.
3. **Analyse** problems and information related to a digital problem.
5. **Synthesise** information to develop possible low-fidelity components of secure data exchange solutions.
7. **Evaluate** components and solutions against criteria to make refinements and justified recommendations; evaluate impacts.
