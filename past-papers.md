# Past papers: where to find everything

::: tip Source
The papers are QCAA's 2020–2025 external assessments (CC BY 4.0, © State of Queensland (QCAA)). The PDFs are in each subject's `papers/` folder and linked by year on its **Paper files** page: [English](/english/papers), [Spanish](/spanish/papers), [Business](/business/papers), [Film](/film/papers), [General Maths](/maths/papers), [Digital Solutions](/digital-solutions/papers). English and Film marking guides contain **criteria only**, with no sample essays; the English file is the combined English/EAL guide.
:::

## A good routine for each paper
1. Do it **timed**, without notes.
2. Mark it against the **guide's criteria** (not just the answers).
3. List every lost mark by **question type**.
4. Redo the weakest type from the notes and the solutions.
