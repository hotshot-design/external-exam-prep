# External exam prep

A local VitePress study site for QCAA 2026 Year 12 external exams (English/Othello, Spanish, Business, Film TV & New Media, General Mathematics, Digital Solutions).

```sh
npm install
npm run docs:dev      # http://localhost:5173
npm run docs:build    # static build into .vitepress/dist
```

- Notes, flashcards, glossaries, quizzes, past-paper analysis and worked solutions per subject.
- Past papers (2020–2025) and syllabuses are in each subject's `papers/` and `syllabus/` folders (QCAA material, CC BY 4.0, © State of Queensland (QCAA)).
- Concept diagrams are generated by `python3 scripts/diagrams.py` (page links by `scripts/diagram_sources.py`, which needs macOS and `swiftc -O scripts/xp.swift -o /tmp/xp`).
- Quizzes use `@matinfo/vitepress-plugin-quiz` (GPL-3.0) with a wrapper in `.vitepress/theme/quizLive.ts`.

Model essays, reports, emails and plans are original revision aids, not QCAA samples. Check content against class notes.
