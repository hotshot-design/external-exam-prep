# Spanish – verb and tense reference

::: tip Grammar for the exam
General Spanish grammar, written for revision (tenses that earn marks in the extended response: a range with accuracy). *Vosotros* forms are included for recognition (common in Spain and possibly in stimulus texts); you can use *ustedes* forms in your own writing if your teacher prefers.
:::

## Which tense for which job?
| Purpose in the exam | Tense | Example |
|---|---|---|
| Facts, habits, current opinions | Present | Creo que el voluntariado es importante. |
| Completed past event | Preterite | El año pasado trabajé como voluntaria. |
| Past habit, description, background | Imperfect | Cuando era pequeño, vivía en Brisbane. |
| Plans (close, informal) | `ir a` + infinitive | Voy a estudiar medicina. |
| Predictions, promises, plans (formal) | Future | Estudiaré en la universidad. |
| Polite wishes, advice, hypotheticals | Conditional | Me gustaría viajar. Deberías ahorrar. |
| Recent past linked to now | Present perfect | He terminado mis exámenes. |
| Wishes, doubts, emotions, future "when" | Present subjunctive | Cuando termine, viajaré. Espero que tengas éxito. |
| Unreal "if" situations | Imperfect subjunctive + conditional | Si tuviera tiempo, haría voluntariado. |

## 1. Present tense

### Regular
| | hablar | comer | vivir |
|---|---|---|---|
| yo | hablo | como | vivo |
| tú | hablas | comes | vives |
| él / ella / usted | habla | come | vive |
| nosotros | hablamos | comemos | vivimos |
| vosotros | habláis | coméis | vivís |
| ellos / ustedes | hablan | comen | viven |

### Key irregulars
| | ser | estar | ir | tener | hacer | poder |
|---|---|---|---|---|---|---|
| yo | soy | estoy | voy | tengo | hago | puedo |
| tú | eres | estás | vas | tienes | haces | puedes |
| él/ella | es | está | va | tiene | hace | puede |
| nosotros | somos | estamos | vamos | tenemos | hacemos | podemos |
| vosotros | sois | estáis | vais | tenéis | hacéis | podéis |
| ellos | son | están | van | tienen | hacen | pueden |

More: `querer` (quiero), `venir` (vengo), `decir` (digo), `saber` (sé), `salir` (salgo), `poner` (pongo), `ver` (veo), `dar` (doy).

### Stem-changers (boot verbs)
`e → ie` (querer, pensar, preferir) · `o → ue` (poder, volver, dormir) · `e → i` (pedir, seguir). Not *nosotros* or *vosotros*.

### Ser vs estar
- **Ser:** identity, origin, profession, characteristics, time (Soy estudiante. Es importante.)
- **Estar:** location, temporary state, emotion, ongoing action (Estoy nervioso. Estoy estudiando.)

## 2. Preterite (completed past)

### Regular
| | hablar | comer / vivir |
|---|---|---|
| yo | hablé | comí / viví |
| tú | hablaste | comiste / viviste |
| él/ella | habló | comió / vivió |
| nosotros | hablamos | comimos / vivimos |
| vosotros | hablasteis | comisteis / vivisteis |
| ellos | hablaron | comieron / vivieron |

### Irregulars
| Verb | yo | él/ella | ellos |
|---|---|---|---|
| ser / ir | fui | fue | fueron |
| tener | tuve | tuvo | tuvieron |
| hacer | hice | hizo | hicieron |
| estar | estuve | estuvo | estuvieron |
| poder | pude | pudo | pudieron |
| poner | puse | puso | pusieron |
| venir | vine | vino | vinieron |
| decir | dije | dijo | dijeron |
| ver | vi | vio | vieron |
| dar | di | dio | dieron |

**Spelling changes in *yo*:** `-car → qué` (busqué), `-gar → gué` (llegué), `-zar → cé` (empecé).
**Third-person `-er/-ir` verbs after a vowel:** `leer → leyó, leyeron`; `construir → construyó`.

## 3. Imperfect (background and habit)
| | hablar | comer / vivir | ser | ir | ver |
|---|---|---|---|---|---|
| yo | hablaba | comía / vivía | era | iba | veía |
| tú | hablabas | comías / vivías | eras | ibas | veías |
| él/ella | hablaba | comía / vivía | era | iba | veía |
| nosotros | hablábamos | comíamos / vivíamos | éramos | íbamos | veíamos |
| vosotros | hablabais | comíais / vivíais | erais | ibais | veíais |
| ellos | hablaban | comían / vivían | eran | iban | veían |

**Only three irregulars:** ser, ir, ver.
**Common signals:** `siempre`, `a menudo`, `de niño/a`, `mientras`, `cada día`.
**Together:** *Mientras estudiaba* (imperfect, background), *llamó mi amigo* (preterite, interruption).

---

## 4. Future and conditional
Both use the **infinitive** as the stem.

| | Future endings | Conditional endings |
|---|---|---|
| yo | -é | -ía |
| tú | -ás | -ías |
| él/ella | -á | -ía |
| nosotros | -emos | -íamos |
| vosotros | -éis | -íais |
| ellos | -án | -ían |

Example: `viajar → viajaré, viajarías`.

### Irregular stems (same for both)
| Infinitive | Stem | Future *yo* | Conditional *yo* |
|---|---|---|---|
| tener | tendr- | tendré | tendría |
| hacer | har- | haré | haría |
| poder | podr- | podré | podría |
| poner | pondr- | pondré | pondría |
| salir | saldr- | saldré | saldría |
| venir | vendr- | vendré | vendría |
| decir | dir- | diré | diría |
| saber | sabr- | sabré | sabría |
| querer | querr- | querré | querría |
| haber | habr- | habré | habría |

**Useful conditionals:** `me gustaría`, `me encantaría`, `podría`, `debería`, `sería`, `habría`.

---

## 5. Present perfect and gerund
**Present perfect:** `haber` + past participle: he, has, ha, hemos, habéis, han + `-ado` / `-ido`.
Irregular participles: `hecho`, `dicho`, `visto`, `escrito`, `puesto`, `vuelto`, `abierto`, `roto`.
*Example:* He aprendido mucho este año.

**Gerund:** `-ando` / `-iendo` (irregular: `leyendo`, `diciendo`, `durmiendo`).
Constructions: `estar` + gerund (ongoing), `seguir` + gerund (keep on), `llevar` + time + gerund (have been doing for).
*Example:* Llevo cinco años estudiando español.

---

## 6. Present subjunctive

**Formation:** take the *yo* form of the present, drop `-o`, add the "opposite" endings.
| | `-ar` verbs (hablar → hablo) | `-er/-ir` verbs (comer → como) |
|---|---|---|
| yo | hable | coma |
| tú | hables | comas |
| él/ella | hable | coma |
| nosotros | hablemos | comamos |
| vosotros | habléis | comáis |
| ellos | hablen | coman |

**Irregular:** `ser → sea`, `estar → esté`, `ir → vaya`, `saber → sepa`, `dar → dé`, `haber → haya`.
**Stem from *yo* form:** `tener → tenga`, `hacer → haga`, `poder → pueda`, `venir → venga`, `salir → salga`, `decir → diga`.

### When to use (WEIRDO)
| Trigger | Example |
|---|---|
| **W**ishes | Quiero que mi hermano me ayude. |
| **E**motions | Me alegra que tengas éxito. |
| **I**mpersonal expressions | Es importante que estudiemos. |
| **R**ecommendations | Recomiendo que ahorres dinero. |
| **D**oubt/denial | Dudo que sea fácil. |
| **O**jalá | Ojalá que haga buen tiempo. |

### Time clauses about the future
`cuando`, `en cuanto`, `después de que`, `hasta que`: Cuando **termine** el colegio, viajaré. *(Not subjunctive for habits: Cuando termino, siempre descanso.)*

**Remember:** `creo que` + indicative; `no creo que` + subjunctive.

---

## 7. Imperfect subjunctive and `si` clauses

**Formation:** take the *ellos* preterite, drop `-ron`, add `-ra, -ras, -ra, -ramos, -rais, -ran`.
| Verb | *ellos* preterite | *yo* imperfect subjunctive |
|---|---|---|
| tener | tuvieron | tuviera |
| hacer | hicieron | hiciera |
| ir / ser | fueron | fuera |
| poder | pudieron | pudiera |
| venir | vinieron | viniera |
| estudiar | estudiaron | estudiara |

**`Si` + imperfect subjunctive → conditional** (hypothetical):
- Si tuviera más tiempo, haría voluntariado.
- Si pudiera, viviría en España.
- Si fuera rico, ayudaría a mi comunidad.

**`Si` + present → future** (real possibility):
- Si estudio mucho, aprobaré el examen.

**Polite/soft requests:** `Quisiera hablar con usted.` `Me gustaría que vinieras.`

---

## 8. Reflexive verbs
Pronouns: **me, te, se, nos, os, se** before the verb: `Me levanto`, `Nos graduamos`, `Me voy a mudar` / `Voy a mudarme`.
Useful: `independizarse`, `mudarse`, `graduarse`, `acostumbrarse a`, `quedarse`, `despedirse`, `sentirse`.

---

## 9. Common errors
| Error | Correct |
|---|---|
| Voy a estudio medicina | Voy a **estudiar** medicina |
| Cuando termino, voy a viajar (future meaning) | Cuando **termine**, voy a viajar |
| Si tendría tiempo | Si **tuviera** tiempo |
| Yo soy nervioso (temporary) | Yo **estoy** nervioso |
| Hablé (habitual past) | **Hablaba** (imperfect) |
| Creo que sea | Creo que **es** |
| Missing accents: hablo / habló | `habló` (preterite) ≠ `hablo` (present) |

## 10. Practice (answers below)
Fill in with the correct form.
1. Cuando (terminar) ___ el colegio, (viajar) ___ a Argentina.
2. Si (tener, yo) ___ más tiempo, (hacer) ___ voluntariado.
3. El año pasado (yo, trabajar) ___ como voluntaria.
4. Mientras (yo, estudiar) ___, mi hermano (jugar) ___ al fútbol.
5. Espero que (tú, poder) ___ venir.
6. Mañana (nosotros, salir) ___ temprano.
7. Me gustaría que (tú, venir) ___ conmigo.
8. Ayer (ellos, hacer) ___ un proyecto de reciclaje.
9. Es importante que los jóvenes (ayudar) ___ a la comunidad.
10. Llevo dos años (aprender) ___ español.

### Answers
1. termine, viajaré · 2. tuviera, haría · 3. trabajé · 4. estudiaba, jugaba · 5. puedas · 6. saldremos · 7. vinieras · 8. hicieron · 9. ayuden · 10. aprendiendo
