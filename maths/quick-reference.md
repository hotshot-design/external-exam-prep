# General Maths – exam-day quick reference

::: tip Papers (2023–25)
**Paper 1:** 57 marks (15 MC + 10 short), about 1.6 min per mark. **Paper 2:** 38 marks, about 2.4 min per mark. 5 min perusal + 90 min each. Scientific calculator, formula book provided. Show working for any question worth more than 1 mark, and finish "justify/evaluate" questions with a decision.
:::

## Method sheet (check the formula book for notation)
| Topic | Method |
|---|---|
| Time zones | difference = offset difference; east is ahead; 15° = 1 h; add 1 h for daylight saving (NZ summer GMT+13) |
| Distance on a meridian | $D = 111.2 \times \text{angular distance}$; opposite hemispheres **add** angles |
| Distance on a parallel | $D = 111.2 \times \cos(\text{latitude}) \times \text{angular distance}$ |
| Compound interest | $A = P(1+i)^n$; $i$ = rate ÷ periods; $n$ = years × periods |
| Effective annual rate | $(1+i)^n - 1$ with $n$ periods per year |
| Reducing-balance loan | $A_{n+1} = (1+i)A_n - d$; interest = payments − reduction in balance |
| Perpetuity | payment $= \text{principal} \times i$; value $= \dfrac{\text{payment}}{i}$ |
| Arithmetic / geometric | $t_n = t_1 + (n-1)d$ and $t_n = t_1 r^{\,n-1}$ (check by differences or ratios) |
| Least-squares line | enter data on the calculator for a and b; slope = change in $y$ per unit $x$; $R^2$ = % of variation explained |
| Correlation | r near ±1 strong; association ≠ causation; a confounding variable affects the response |
| Seasonal index | season ÷ that year's mean, averaged over years; deseasonalised = value ÷ index |
| Networks | MST (Kruskal/Prim); Euler trail: 0 or 2 odd vertices; max flow = min cut; critical path: EST forward, LST backward, float = LST − EST |
| Assignment (Hungarian) | reduce rows, reduce columns, cover zeros; lines = tasks, then allocate |
| Euler's formula | $v + f - e = 2$ for planar graphs |

## Recurring Paper 2 shapes
Table or story → **make the representation** (scatterplot, weighted graph, flow network, table of values) → reason from it → **state a decision** with numbers.
