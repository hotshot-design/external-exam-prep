#### Q20 (4 marks) Straight-line depreciation: identify the model
**Arithmetic sequence:** $t_{1} = 45\,100, d = -2700$. The start of 2021 is the 10th term (2012 is the 1st), so n = 10.
$t_{10} = 45\,100 - 2700 \times 9 =$ **\$20 800**.
**Linear model (alternative):** y = −2700x + 45 100 with x = 9 years: y = **\$20 800**.
**Marks (guide):** model (1), parameters (1), substitution (1), answer with units (1).
*Watch the term number:* start of 2012 is term 1, so start of 2021 is term 10, not 9 or 11.

#### Q22 (4 marks) Reducing-balance loan: balance after 2 months

#### Q23 (4 marks) Flow network: valid cuts 📐
a) **L4 is not a valid cut** because the tank (source) and the tap (sink) are on the **same side** of the line (1).
b) Add only capacities pointing **from the source side to the sink side**:
L1 = 20 + 22 + 15 = **57**; L2 = 18 + 19 + 22 + 15 = **74**; L3 = 18 + 8 + 10 = **36** (1 mark each).
The minimum cut is L3 = 36, so the maximum flow is 36 (not asked, but this is how it is usually used).

## Paper 2 (38 marks)

#### Q1 (4 marks) Latitude, longitude and time
The yacht and home share a latitude: **14°52′ S** (1).
Sunrise 1 h 13 min later at home means home is **west** of the yacht by 1.2167 h × 15° = **18.25° = 18°15′** (1).
Longitude of home = 145°29′ − 18°15′ = **127°14′ E** (2 marks: subtract in the same format; correct longitude).
**Coordinates: 14°52′ S, 127°14′ E.**
*Idea:* later sunrise means further west (the sun reaches the east first).

#### Q3 (5 marks) Future value annuity plus a lump sum
i = 0.036 ÷ 4 = 0.009 per quarter; regular contributions for 6 × 4 = 24 quarters (1).
$A = 2500 \times (1.009^{24} - 1) \div 0.009 =$ **\$66 639.94** (1).
Extra \$10 000 at the end of year 4 grows for 2 years = 8 quarters: $10\,000 \times 1.009^{8} =$ **\$10 743.09** (1 + 1).
Total = 66 639.94 + 10 743.09 = 77 383.03 ≈ **\$77 383** (1).
*Key idea:* treat the lump sum as a separate compound-interest investment and add the two.

#### Q4 (6 marks) Compare geometric and arithmetic growth from a graph 📐
Let n = years since 2019, so 2020 is n = 1.
**Model 1 (geometric):** $t_{1} = 250$, and 2038 is n = 19 with value 2750. $2750 = 250 \times r^{18}$, so $r^{18} = 11$ and **r = 1.1425**. $t_{n} = 250 \times 1.1425^{n-1}$ (2 marks).
**Model 2 (arithmetic):** the line starts at \$0 in 2020 with d = 126: **$t_{n} = 126(n - 1)$** (1).
2030 is n = 11: Model 1 $= 250 \times 1.1425^{10} =$ **\$947.33** (the guide's value, using r rounded to 1.1425; the unrounded r gives 947.31); Model 2 = 126 × 10 = **\$1260** (1).
Difference = 1260 − 947.33 = 312.67 ≈ **\$313** (Model 2 is higher) (1). Logical organisation (1).

#### Q5 (6 marks) Rebuild a least-squares line from r, standard deviations and a residual
Given: r = 0.875, s_x = 4 (age), s_y = 6, the 31-year-old has y = 119 and the residual plot shows a residual of −0.75 at age 31.
Predicted y at 31 = 119 − (−0.75) = **119.75** (1) (residual = actual − predicted).
Slope b = r × s_y ÷ s_x = 0.875 × 6 ÷ 4 = **1.3125** (1).
Intercept: 119.75 = 1.3125 × 31 + a, so **a = 79.0625** (1).
Oldest person (40): predicted = 1.3125 × 40 + 79.0625 = **131.5625** (1). The residual plot shows +1.4 at age 40, so actual = 131.5625 + 1.4 = 132.9625 ≈ **133** (1). Organisation (1).
**Marks (guide):** predicted y, b, a, predicted at 40, actual BP as a whole number, organisation.
*Key idea:* actual = predicted + residual.

#### Q6 (7 marks) Hungarian algorithm with an unknown x (complex unfamiliar) 📐
Matrix (distances): A: P x+6, Q 2x+3, R x+7; B: P x+3, Q 2x+4, R x+5; C: P x, Q 2x+1, R x+3.
Row reduction: A [0, x−3, 1], B [0, x+1, 2], C [0, x+1, 3].
Column reduction (subtract x − 3 from column Q, 1 from column R): [0, 0, 0], [0, 4, 1], [0, 4, 2].
Only 2 lines cover all zeros, so adjust: add 1 to the doubly-covered cell and subtract 1 from uncovered entries, giving [1, 0, 0], [0, 3, 0], [0, 3, 1].
Optimal allocation: **A → Q, B → R, C → P**. Total = (2x + 3) + (x + 5) + x = 4x + 8.
4x + 8 = 32, so **x = 6**. The distance from Tow Truck C to Motorist P is **6 km**.
**Marks (guide):** matrix (1), row reduction (1), column reduction (1), algorithm applied (1), allocation (1), x (1), organisation (1).
*Check:* the other five pairings give 4x + 9 to 4x + 13, all larger.

#### Q7 (6 marks) Evaluate reasonableness with exponential growth
Let n = number of 5-day blocks and t = total plays (thousands): 8, 12, 18, 27 so r = 12 ÷ 8 = **1.5** (variables 1, r 1). Model **$t_{n} = 8 \times 1.5^{n-1}$** (1).
60 days is n = 12: $t_{12} = 8 \times 1.5^{11} =$ **691.98 thousand** plays (1).
Income = 0.175 cents × 691 980 = 121 096.5 cents = **\$1210.97** (1).
\$1210.97 > \$1000, so the prediction of **at least \$1000 is reasonable**, provided the exponential pattern continues (1).
